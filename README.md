SpendWise AI Pro

A smart budget advisor that shows where your salary goes, estimates tax for 17 countries, and suggests how to save more and enjoy time with family.

https://monthlybudgetsai.netlify.app

## ✨ Features
- Tax estimate by country: income tax, social contributions and hidden VAT/GST
- Monthly expense tracking: rent, EMI, petrol, food, bills, insurance, health, education
- Family support, investment and savings planning
- Money health score (0–100) with a donut chart
- 50/30/20 ideal budget comparison
- AI Advisor chat (rules-based) with expense-cutting tips, investing ideas and an emergency fund plan
- Family fun plan: free, weekend and yearly trip budgets
- Colourful glassmorphism UI, mobile friendly

## 🌍 Supported countries
India, USA, UK, Germany, UAE, Saudi Arabia, Qatar, Canada, Australia, New Zealand, Singapore, Malaysia, Japan, France, Netherlands, Ireland, Switzerland

## 🛠️ Tech stack
HTML, CSS, JavaScript (no frameworks, no build step)

## 🚀 Run locally
1. Download or clone this repo
2. Open `index.html` in your browser

## ☁️ Deploy on Netlify
Drag and drop the project folder to https://app.netlify.com/drop

## ⚠️ Disclaimer
Tax rules are simplified estimates and the advisor is rules-based, not a live AI model. This is not financial or tax advice.
